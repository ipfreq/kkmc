# ملفات المشاريع

- `full-project.json`: المشروع كامل بكل بنود العقد الـ 26 وجدول الأعمال المتبقية.
- `remaining-works-only.json`: الأعمال المتبقية فقط (بدون بنود العقد).

لفتح أي ملف: من الصفحة افتح تبويب «خطة العمل» ثم «فتح ملف مشروع»، أو من الفهرس «فتح ملف مشروع»، ويُضاف كمشروع جديد.
المشروعان موجودان أيضاً داخل الصفحة نفسها وداخل النسخة المحلية.
