# متابعة المشاريع (Project Tracker)

برنامج سطح مكتب لويندوز 10 و11 لمتابعة مشاريع المقاولات: حصر الأعمال، الجدول الزمني، المحابس المركبة، التوريدات، المصاريف، أوامر الإيقاف وإضافة المدد، وتقارير PDF وExcel.

تصميم وبرمجة: م. ياسر محمد عبدالجابر · © 2026 جميع الحقوق محفوظة (انظر `LICENSE.txt`).

## التسطيب
نزّل ملف `ProjectTracker-Setup-x.y.z.exe` من صفحة **Releases** في المستودع وشغّله.
لأن الملف غير موقّع رقمياً، قد يظهر تحذير Windows SmartScreen: اضغط «More info» ثم «Run anyway»،
أو قبل التشغيل: كليك يمين على الملف ← Properties ← علّم «Unblock» ← OK، فلا يظهر التحذير.

عند تشغيل ملف التسطيب والبرنامج مثبت بالفعل تظهر صفحة باختيارات: **إصلاح البرنامج**، **إعادة التثبيت بالكامل**، **إزالة البرنامج**.
بيانات المشاريع في `المستندات\Project Tracker` لا تُحذف في أي اختيار.

### التوقيع الرقمي (لإزالة تحذير SmartScreen)
1. اشترِ شهادة توقيع كود (Code Signing) واحصل عليها كملف `.pfx` بكلمة مرور.
2. في المستودع على GitHub: Settings ← Secrets and variables ← Actions ← New repository secret:
   - `WIN_CSC_LINK`: محتوى ملف الـ pfx بصيغة base64 (في PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("cert.pfx"))`).
   - `WIN_CSC_KEY_PASSWORD`: كلمة مرور الشهادة.
3. أي بناء بعدها يخرج موقّعاً تلقائياً باسم صاحب الشهادة.

## المشاريع
عند أول تشغيل (أو بعد «إعادة ضبط البرنامج») يحتوي البرنامج على مشروعين: مشروع توريد وتركيب المحابس، ومشروع الأعمال المتبقية في محطات الرفع.
كل مشروع له نفس الأقسام: لوحة المتابعة، حصر الأعمال، الجدول الزمني، البنود المنفذة، التوريدات، المصاريف، الإيقاف والمدد، خطة العمل، التقرير / PDF، بيانات المشروع.
- **مشروع جديد**: اكتب الاسم فقط.
- **البنود المنفذة**: سلايدر لكل بند يحدد نسبة التنفيذ حتى 100%، أو تُحسب النسبة من سجل الكميات المنفذة.
- **إخفاء تبويب**: من بيانات المشروع ← التبويبات الظاهرة.
- **زر «+»** لإضافة بند جديد من نموذج التنفيذ والتوريد، ولإضافة تصنيف من نموذج المصاريف.

## أدوات قاعدة البيانات (في الصفحة الرئيسية)
- **نسخ قاعدة البيانات**: يحفظ نسخة من ملف كل المشاريع لنقلها لجهاز آخر.
- **تحميل قاعدة بيانات**: يفتح ملف قاعدة بيانات من جهاز آخر، ويضيف مشاريعه للمشاريع الحالية أو يستبدلها كلها.
- **فتح مجلد قاعدة البيانات**.
- **إعادة ضبط البرنامج**: يحذف كل المشاريع وقاعدة البيانات والنسخ الاحتياطية السابقة ويعيد المشروعين الافتراضيين (يتطلب كتابة كلمة «تصفير»).

## الترخيص

- أول تشغيل على أي جهاز يبدأ فترة تجريبية مدتها 7 أيام، وبعدها يطلب البرنامج رقم ترخيص.
- كل جهاز له «رقم جهاز» خاص يظهر في صفحة التفعيل، ورقم الترخيص يعمل على هذا الجهاز فقط.
- البيانات لا تُحذف عند انتهاء الفترة التجريبية، ويمكن نسخ قاعدة البيانات من صفحة التفعيل.
- إصدار التراخيص يتم من صفحة التفعيل (Ctrl+Shift+K) بملف المفتاح الخاص، وهو غير موجود في هذا المستودع ولا يُرفع عليه أبداً.

## البيانات
- كل المشاريع في ملف قاعدة بيانات واحد (SQLite): `المستندات\Project Tracker\projects.db`.
- نسخة احتياطية تلقائية كل يوم في `المستندات\Project Tracker\backups` (آخر 30 يوماً)، ونسخة قبل أي حذف أو استرجاع.
- لنقل بياناتك من نسخة المتصفح: صدّر «ملف المشروع (JSON)» أو «نسخة Excel كاملة» منها، ثم «استيراد مشروع من ملف» في البرنامج.

## للمطوّر
```
python3 src/valves/build.py --desktop desktop/renderer   # يبني صفحة المشروع
cd desktop && npm ci && npm start                         # تشغيل البرنامج
npm run dist                                              # ملف التسطيب (على ويندوز)
```
ملف التسطيب يُبنى تلقائياً على GitHub Actions عند كل تعديل ويُنشر في Releases.
