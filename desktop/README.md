# متابعة المشاريع (Project Tracker)

برنامج سطح مكتب لويندوز 10 و11 لمتابعة مشاريع المقاولات: حصر الأعمال، الجدول الزمني، المحابس المركبة، التوريدات، المصاريف، أوامر الإيقاف وإضافة المدد، وتقارير PDF وExcel.

تصميم وبرمجة: م. ياسر محمد عبدالجابر · © 2026 جميع الحقوق محفوظة (انظر `LICENSE.txt`).

## التسطيب
نزّل ملف `ProjectTracker-Setup-x.y.z.exe` من صفحة **Releases** في المستودع وشغّله.
لأن الملف غير موقّع رقمياً، قد يظهر تحذير Windows SmartScreen: اضغط «More info» ثم «Run anyway».

## أنواع المشاريع
- **مشروع محابس**: حصر الأعمال، الجدول الزمني، المحابس المركبة، التوريدات، المصاريف، الإيقاف والمدد، خطة العمل، تقارير PDF وExcel. يبدأ من القالب الكامل أو فارغاً.
- **خطة عمل وجدول زمني**: برنامج خطط محطات الرفع (مراحل ومهام وGantt وجدول كميات وتقرير PDF)، ويمكن أن يضم أكثر من خطة. «خطط محطات الرفع – مدينة الملك خالد العسكرية» يُضاف تلقائياً عند أول تشغيل.

## البيانات
- كل المشاريع في ملف قاعدة بيانات واحد (SQLite): `المستندات\Project Tracker\projects.db`.
- نسخة احتياطية تلقائية كل يوم في `المستندات\Project Tracker\backups` (آخر 30 يوماً)، ونسخة قبل أي حذف أو استرجاع.
- لنقل بياناتك من نسخة المتصفح: صدّر «ملف المشروع (JSON)» أو «نسخة Excel كاملة» منها، ثم «استيراد مشروع من ملف» في البرنامج.

## للمطوّر
```
python3 src/valves/build.py --desktop desktop/renderer   # يبني صفحة المشروع
cd desktop && npm ci && npm start                         # تشغيل البرنامج
npm run dist                                              # ملف التسطيب (على ويندوز)
```
ملف التسطيب يُبنى تلقائياً على GitHub Actions عند كل تعديل ويُنشر في Releases.
