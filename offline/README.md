# النسخة المحلية (بدون إنترنت)

افتح الملف `projects-plan-offline.html` بأي متصفح (Chrome أو Edge أو Safari) بالضغط عليه مرتين.

- يعمل بالكامل بدون إنترنت: الخطوط ومكتبات تحويل الـ PDF مدمجة داخل الملف.
- التعديلات تُحفظ تلقائياً في المتصفح على نفس الجهاز.
- زر «حفظ نسخة محدّثة من الملف» يحمّل ملف HTML جديد فيه كل المشاريع والتعديلات، افتحه بدل النسخة القديمة أو أرسله لغيرك.
- «حفظ ملف المشروع» و«فتح ملف مشروع» لنقل المشاريع بين الأجهزة.

## مشروع توريد وتركيب محابس البنية التحتية

افتح الملف `kkmc-valves-project-offline.html` (يعمل بدون إنترنت). النسخة المنشورة على GitHub هي `kkmc-valves-project.html` في المجلد الرئيسي.

- **حصر الأعمال**: البنود التسعة بكمياتها، والموَرَّد والمركب يُحسبان تلقائياً من السجلات. أدخل سعر الوحدة لحساب القيم.
- **المحابس المركبة / التوريدات / المصاريف**: سجل كل عملية بتاريخها. أي خانة تُعدّل مباشرة من الجدول، و✕ للحذف، و👁 لإخفاء السجل من التقرير فقط.
- **الإيقاف والمدد**: أمر الإيقاف (من – حتى) يؤخر الجدول الزمني تلقائياً ويضاف للمدة. إضافة المدة تمدد تاريخ الانتهاء.
- **الجدول الزمني**: خطة P6 المعتمدة (250 يوم عمل). اضغط على أي مهمة لتعديلها.
- **خطة العمل**: كل الأقسام والجداول قابلة للتعديل والإضافة والحذف.
- **التقرير / PDF**: اختر الفترة والأقسام، ثم «طباعة / حفظ PDF» (الأدق) أو «تحميل PDF مباشرة».
- **الحفظ**: التعديلات تُحفظ في المتصفح تلقائياً. «حفظ نسخة HTML محدّثة» يحمّل ملفاً كاملاً فيه كل بياناتك؛ افتحه بدل القديم.

لإعادة بناء الملفين بعد تعديل المصدر في `src/valves/`: `python3 src/valves/build.py`
