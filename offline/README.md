# النسخة المحلية (بدون إنترنت)

افتح الملف `projects-plan-offline.html` بأي متصفح (Chrome أو Edge أو Safari) بالضغط عليه مرتين.

- يعمل بالكامل بدون إنترنت: الخطوط ومكتبات تحويل الـ PDF مدمجة داخل الملف.
- التعديلات تُحفظ تلقائياً في المتصفح على نفس الجهاز.
- زر «حفظ نسخة محدّثة من الملف» يحمّل ملف HTML جديد فيه كل المشاريع والتعديلات، افتحه بدل النسخة القديمة أو أرسله لغيرك.
- «حفظ ملف المشروع» و«فتح ملف مشروع» لنقل المشاريع بين الأجهزة.
